# Proyecto_1

MiOCRPotente es un proyecto experimental de reconocimiento óptico de caracteres (OCR) para Windows, desarrollado con C# y basado en Tesseract. Su objetivo es extraer texto desde imágenes y convertirlo en archivos de texto, facilitando la digitalización de contenido visual.

Este repositorio aún se encuentra en desarrollo y puede requerir ajustes, mejoras y validaciones adicionales antes de considerarse una versión estable o completamente finalizada. La aplicación incluye soporte para español y permite procesar imágenes desde el sistema operativo mediante scripts y accesos rápidos.

Entre sus funcionalidades actuales se encuentran:
- Lectura de texto desde imágenes
- Extracción automática de contenido en español
- Generación de archivos .txt con el resultado OCR
- Integración con Windows mediante scripts y registro del sistema
- Ejecución práctica para pruebas y uso inicial

Este proyecto está pensado como una base funcional para pruebas de OCR y como punto de partida para futuras mejoras, optimizaciones y refinamiento del flujo de trabajo.
